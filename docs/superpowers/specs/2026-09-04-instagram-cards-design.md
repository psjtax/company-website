# 세무소식 · 인스타그램 카드 6칸 설계

작성일 : 2026-09-04
정한 사람 : 지윤 대리님 / 만드는 사람 : 빵자

## 왜 만드나

세무소식 페이지 위에 사무소 인스타그램(@taxpsj) 최근 게시물을 **카드 6칸**으로 보여준다.
세무뉴스의 카드 슬라이드와 같은 모양이며, 카드를 누르면 **사이트 안 창**에서 사진과 글을 읽는다.
게시물이 6개보다 적으면 남는 칸은 "준비 중입니다" 카드로 채운다.

블로그 연동(`2026-09-04-column-blog-integration-design.md`)과 같은 페이지에 얹는다.

## 어떻게 가져오나 — 확인해 둔 사실

### 긁어오기는 불가능하다

| 해본 것 | 결과 |
|---|---|
| `instagram.com/taxpsj` 받아오기 | 200 / 718KB 인데 **게시물 데이터 없음**. 로그인한 사람에게만 준다 |
| 공식 임베드 `/p/<코드>/embed/captioned/` | 열린다. 대표 사진 1장 + 설명 608자. **다만 게시물 목록은 못 얻는다** |

목록을 얻는 길은 **공식 API 뿐이다.** 몰래 긁는 방식은 약관 위반이고 깃허브 서버 IP 는 이미 차단되어 있다.

### 이름표 (2026-09-04 확인 완료)

- 대리님이 기존 Meta 앱 `박성진세무 카드뉴스`(앱 ID 1638000058053158)에서 **홈페이지 전용 토큰을 새로 발급**해 저장소 금고 `IG_ACCESS_TOKEN` 에 넣으심
- 권한 `instagram_business_basic` 이 이미 켜져 있음
- `.github/workflows/insta-check.yml` 로 실제 확인 → **Success**. 계정 인식과 게시물 읽기 모두 성공
- 계정은 `taxpsj`, `BUSINESS`, 게시물 1건

**대리님 컴퓨터의 `C:\수업\하네스실습\automation\.env` 는 쓰지 않는다.** 대리님이 아직 만드는 중인 파일이며, 쓰지 말라고 명시하셨다.

### API 로 얻는 것

`GET https://graph.instagram.com/v21.0/me/media`
`fields=id,caption,media_type,media_url,thumbnail_url,permalink,timestamp,children{media_url}`
`limit=6`

- 여러 장짜리(`CAROUSEL_ALBUM`)는 `children` 에 낱장이 들어온다. 지금 있는 게시물은 **8장**
- 사진은 1080×1080, 서버에서 내려받기 **성공**(72KB). 다만 인스타 사진 주소는 **시간이 지나면 만료**되므로 반드시 내려받아 우리 쪽에 둔다

## 이름표 수명 — B+ 방식

인스타 토큰은 **60일**이면 죽는다. 깃허브 토큰처럼 "만료 없음"을 고를 수 없다(메타 정책).

그래서 **스스로 연장**하게 만든다.

```
갱신이 돌 때마다
   └ 남은 수명을 확인
        └ 20일 미만이면
             ├ 인스타에 연장 요청 (refresh_access_token)
             └ 새 토큰을 저장소 금고에 다시 넣기 (깃허브 Secrets API)
```

- 갱신은 하루 두 번 도니 60일을 놓칠 일이 없다
- 금고에 값을 넣으려면 **깃허브 이름표에 `Secrets: Read and write` 권한이 추가로 필요**하다. 대리님이 기존 `NEWS_TOKEN` 에 권한 하나를 더 켜시면 된다
- 금고에 쓸 때는 저장소 공개키로 암호화해서 보낸다(깃허브가 요구하는 방식)
- **연장에 실패해도 그날의 게시물 갱신은 정상 진행**한다. 연장 실패는 경고만 남긴다

### 무너지는 경우

자동 갱신이 **60일 넘게 멈춰 있으면** 연장을 못 받아 토큰이 죽는다. 그때는 대리님이 Meta 콘솔에서 새 토큰을 발급해 금고에 다시 넣어야 한다.
어제 넣은 60일 규칙 대비책(`news-autoupdate`) 덕분에 갱신이 멈출 가능성은 낮다.

## 글 다듬기 (대리님 결정)

인스타 설명글을 그대로 쓰면 안 되는 것이 둘 있다.

| 무엇 | 어떻게 | 왜 |
|---|---|---|
| `📞 051-710-9685` | **그 줄을 통째로 지운다** | 사무실 번호는 사이트 어디에도 노출하지 않기로 함 |
| 맨 끝 해시태그 줄 | **지운다** | 인스타에선 필요하지만 홈페이지에선 어색하다 |

- 해시태그 판정 : 줄에서 공백을 뺀 내용이 전부 `#...` 토큰이면 그 줄을 버린다. 문장 중간의 `#` 은 건드리지 않는다
- 전화번호 판정 : `051-710-9685` 와 숫자만 남긴 `05171 09685` 형태를 모두 본다
- 설명글에 이미 "본 콘텐츠는 일반적인 안내이며…" 문구가 있으므로 우리 쪽 주의 문구는 따로 붙이지 않는다

## 화면

- **자리** — 세무소식 페이지 `<section class="page">` 안, 목록(`news-box`) **위**
- **카드** — 세무뉴스의 `.nc-wrap` / `.nc-track` / `.nc` 를 그대로 쓴다. 좌우 화살표도 그대로
- **카드에 보이는 것** — 대표 사진, 날짜, 설명 앞부분
- **준비중 카드** — 실제 게시물 수가 6보다 적으면 나머지는 `준비 중입니다` 카드. 눌러도 아무 일 없음
- **누르면** — 기존 읽는 창(`.nv-*`)에 **사진 전부 + 설명글**. 창 아래 `인스타그램에서 보기` 링크
- 블로그 글의 읽는 창과 같은 창을 나눠 쓴다

## 파일

| 파일 | 역할 |
|---|---|
| `tools/update_insta.py` | **새로.** 게시물 받아오기 · 글 다듬기 · 사진 저장 · HTML 갈아끼우기 |
| `tools/refresh_insta_token.py` | **새로.** 토큰 수명 확인과 연장, 금고에 다시 넣기 |
| `column/index.html` | 카드 자리와 표시자(`<!-- 인스타 여기부터 --> ~ <!-- 인스타 여기까지 -->`) |
| `column/insta/` | **새로.** 내려받아 크기 줄인 사진 |
| `.github/workflows/news.yml` | 단계 두 개 추가 |
| `style.css` | 준비중 카드 모양만 조금 |

블로그 쪽 `tools/update_column.py` 는 건드리지 않는다. 같은 페이지를 고치지만 표시자가 서로 다르다.

## 잘못됐을 때

| 상황 | 어떻게 |
|---|---|
| 인스타가 안 열림 / 토큰 만료 | **아무것도 바꾸지 않고** 종료 1. 기존 화면 유지 |
| 게시물이 0건으로 옴 | **쓰지 않는다.** 있던 카드를 지우면 안 된다 |
| 사진 한 장 실패 | 그 사진만 빼고 진행 |
| 사진이 전부 실패 | 그 게시물은 사진 없이 글만 |
| 토큰 연장 실패 | 경고만 남기고 게시물 갱신은 계속 |
| 바뀐 것 없음 | 커밋하지 않는다 |

블로그 연동과 같은 안전장치를 그대로 적용한다 : 빈 결과 차단, 줄 수가 크게 줄면 중단, 임시파일 + `os.replace` 로 원자적 쓰기.

## 확인 방법

1. `python tools/update_insta.py` 를 손으로 돌려 결과를 본다 (토큰은 환경변수로 준다)
2. 띄워서 카드 6칸 · 준비중 카드 · 읽는 창 · 사진을 눈으로 본다
3. 전화번호와 해시태그가 정말 지워졌는지 확인한다
4. 미리보기를 만들어 **대리님께 먼저 보여드리고**, 확인받은 뒤 올린다

## 아직 안 정한 것

- 토큰 연장이 금고에 값을 넣으려면 `NEWS_TOKEN` 에 권한 추가가 필요하다. **대리님 클릭이 필요한 유일한 남은 일**
- 카드가 1개뿐일 때 좌우 화살표를 감출지는 화면을 보고 정한다
